# Wine dataset

Aeberhard, S. & Forina, M. (1992). Wine [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5PC7J

Source: https://archive.ics.uci.edu/dataset/109/wine

This CSV was exported from scikit-learn’s bundled `load_wine()` dataset: https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_wine.html

It contains 178 observations, 13 numeric chemical features, and a cultivar label (1–3). The label is used only to color the PCA plots and is excluded from the covariance matrix. Values are unchanged; the label is converted from scikit-learn’s 0–2 coding to 1–3. The bundled copy allows offline execution without installing scikit-learn.
